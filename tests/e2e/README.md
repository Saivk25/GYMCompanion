# End-to-end tests

Full-stack tests spanning the Flutter client and the backend together, covering the
critical flows named in the Engineering Master Plan Section 9: onboarding, the daily
loop, safety escalation, meal logging. This is distinct from:

- `backend/tests/` — backend unit and integration tests (no Flutter involved).
- `apps/mobile/test/` — Flutter widget tests (no backend involved).

Populated starting Sprint 5, once there is a full flow to test end to end.
