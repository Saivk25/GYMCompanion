# Datasets

Reserved for future use. The Engineering Master Plan (Section 1, "what we are
deliberately not building yet") is explicit that no custom model training is planned
through v1 — everything AI-related is a call to a cloud provider behind the AI Adapter
Layer (`backend/app/ai/`). This directory exists so the repository layout would not
need to change if a genuinely justified training need appears later; it holds nothing
today.
